## Goal

SUA keeps an agent faithful to the current authorized user objective over
long work: Goal Control → Task Control → Context Control → Evidence Control →
Knowledge. It stores reusable knowledge while controlling what enters current
attention. The portable rules library is its delivery form; AI4S K0–K7 is a
domain adapter. Legacy self-modifying runtime code remains in the repository.
